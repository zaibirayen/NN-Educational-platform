Neural Network Fundamentals

A comprehensive course explaining the core concepts behind neural networks used in this project.

1. What is a Neural Network?

A neural network is a computational model inspired by the biological neural networks in animal brains. It consists of interconnected nodes (neurons) organized in layers that process information.

Neural networks learn by adjusting the weights between connections based on the error between predicted and actual outputs. This process is called training.

Key Insight: Neural networks are particularly good at finding complex patterns in data, making them ideal for classification and regression tasks.

2. The Perceptron - Single Neuron

The perceptron is the simplest form of a neural network - a single neuron that makes decisions by weighing input evidence.

A perceptron takes multiple inputs, multiplies each by a weight, sums them up, and applies an activation function to produce an output.

Formula:
output = activation(Σ(wᵢ × xᵢ) + b)
Where wᵢ are weights, xᵢ are inputs, and b is the bias.

3. Multi-Layer Perceptron (MLP)

An MLP consists of:

  • Input Layer: Receives the raw data features
  • Hidden Layer(s): Process and transform the data through weighted connections
  • Output Layer: Produces the final prediction

Our project uses the MLP architecture, which can learn non-linear relationships in data through multiple hidden layers.

4. Forward Propagation

Forward propagation is the process of passing input data through the network to generate an output:

  1. Inputs are received at the input layer
  2. Each neuron computes a weighted sum of its inputs
  3. An activation function transforms the sum into an output
  4. This output becomes the input for the next layer
  5. The process repeats until the output layer produces a result
Activation Functions: Common activation functions include ReLU, Sigmoid, and Tanh. They introduce non-linearity, allowing the network to learn complex patterns.

5. Backward Propagation (Backpropagation)

Backpropagation is the learning algorithm that adjusts network weights based on prediction errors:

  1. Calculate the error at the output layer (difference between predicted and actual)
  2. Propagate the error backward through the network
  3. Compute how much each weight contributed to the error
  4. Adjust weights to minimize the error

This process uses the chain rule from calculus to compute gradients efficiently.

6. Loss Functions

Loss functions measure how well the network is performing. The goal of training is to minimize this loss.

  • Mean Squared Error (MSE): Used for regression tasks - measures average squared difference between predicted and actual values
  • Cross-Entropy: Used for classification tasks - measures the difference between probability distributions
Tip: Choose MSE for continuous outputs (like price prediction) and Cross-Entropy for categorical outputs (like species classification).

7. Optimizers

Optimizers determine how to update the network weights based on the computed gradients:

  • SGD (Stochastic Gradient Descent): Simple and effective, updates weights in the direction of the negative gradient
  • Adam: Adaptive learning rate optimizer that combines momentum with RMSProp - often the best choice for deep learning

The learning rate is a crucial hyperparameter that controls how big steps the optimizer takes during training.

8. Hyperparameters

Hyperparameters are settings that you configure before training:

  • Number of Hidden Layers: More layers can learn more complex patterns but may overfit
  • Number of Neurons per Layer: More neurons increase model capacity
  • Learning Rate: Controls how fast the model learns
  • Epochs: Number of times the entire dataset is passed through the network
  • Batch Size: Number of samples processed before updating weights

9. Model Evaluation

After training, evaluate your model using various metrics:

  • Accuracy: Percentage of correct predictions
  • Confusion Matrix: Shows true positives, true negatives, false positives, and false negatives
  • Loss Curve: Visualize how loss changes over epochs to detect overfitting
Best Practice: Always split your data into training and testing sets to evaluate how well your model generalizes to unseen data.

10. Summary

Neural networks learn by:

  1. Forward Pass: Processing input data through layers to get predictions
  2. Computing Loss: Measuring prediction error with a loss function
  3. Backward Pass: Propagating errors back through the network
  4. Updating Weights: Using an optimizer to minimize loss

This project implements a Perceptron and MLP for classification tasks, allowing you to experiment with different architectures and hyperparameters.
